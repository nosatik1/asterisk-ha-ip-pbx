# asterisk-ha-ip-pbx
задача
организации сервиса IP-телефонии для промышленной компании 50, с обеспечение отказоустойчивости корпоративной связи на базе двух серверов Asterisk с автоматическим ре-зервированием.

стек
Linux, Asterisk , Docker, bash, PostgreSQL, Keeplived

архитектура

2 сервера (backup/master) с плавающем  vip
сохрзонизация через rsync+ssh, PostgreSQL
веб интерфейс gonoPBX череp Docker

Структура репозитория
keepalived конфигурации для Мастер и Бэкап узлов.
asterisk файлы конфигурации PJSIP, очередей и диалплана.
scripts скрипт автоматической синхронизации.
docker файлы для развертывания веб-интерфейса.
.env.example` — шаблон переменных окружения

 Трудности и решения
Отсутствие sip.conf и переход на PJSIP
При изучении документации и старых руководств ожидалось наличие файла sip.conf для настройки телефонии. Однако в используемой версии Asterisk  этот файл отсутствует
Было выяснено, что начиная с Asterisk 13) стандартом стал драйвер chan_pjsip, который пришел на смену устаревшему chan_sip
